About This Project

The Git Workflow Guide is a small two-page website built by Abhinav Suri as part of coursework on Git and GitHub. The website itself is intentionally simple: its main purpose is to provide real files on which a complete version control workflow can be practised, from the first commit to publishing the project on GitHub.

Branching Strategy

The project uses two branches. The main branch always contains stable, reviewed content. New work is carried out on a separate feature branch and is merged back into main only when it is complete. This keeps the main branch clean and makes every change easy to trace.

What This Project Demonstrates

  • Creating a local repository and recording changes through commits
  • Developing a change on a feature branch and merging it into main
  • Excluding log files and temporary folders with a .gitignore file
  • Undoing a commit safely while keeping the work it contained
  • Publishing the repository and its branches to GitHub

Tools Used

  • HTML5 and CSS for the web pages
  • Git for local version control
  • GitHub for remote hosting of the repository
