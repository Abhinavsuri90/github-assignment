Version Control Made Simple

Every software project changes constantly. Version control keeps a complete, searchable record of those changes so that developers can work with confidence, collaborate safely and return to an earlier state whenever something goes wrong. This site gives a short, practical introduction to Git and GitHub.

Why Use Version Control?

  • Complete history: every change is recorded with an author, a date and a message.
  • Safe experimentation: new ideas can be developed on separate branches without affecting stable code.
  • Collaboration: several people can work on the same project and combine their work cleanly.
  • Recovery: mistakes can be undone by returning to a previous commit.
